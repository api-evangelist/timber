The Vector observability API migrated from GraphQL to gRPC in version 0.55.0. Although Vector is an observability tool, it’s nonetheless important to be able to observe Vector itself, especially in production environments where it serves as critical infrastructure. That’s why we’re excited to announce the new Vector GraphQL API , available in v0.11.0 .
